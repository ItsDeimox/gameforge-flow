# GameForge Flow

Aplicativo local-first para organizar a produção de jogos entre **Visão**, **Produção** e **Execução**.

A versão atual inclui colaboração em rede local ou túnel, equipes e permissões por Save, presença em tempo real, comentários, anexos e integração MCP.

## Executar

1. Abra `outputs/GameForge_Flow_v0.4`.
2. Execute `START.bat`.
3. Acesse `http://127.0.0.1:8765`.

As instruções completas de instalação, conexão e MCP estão em [`outputs/GameForge_Flow_v0.4/README.md`](outputs/GameForge_Flow_v0.4/README.md).

O pacote pronto para distribuição está em [`outputs/GameForge_Flow_v0.9.0.zip`](outputs/GameForge_Flow_v0.9.0.zip).
